# Study_hours_tracker
Python project to track daily study hours"


💻✨ Just built a small but useful Python project to track my daily study hours!

I wanted a simple way to log how many hours I study each day and calculate the total over time. So I created a program that:
✅ Appends new study records (date & hours) to a text file
✅ Reads all records and converts them into time durations
✅ Calculates & displays the total study hours in a clean format

🔧 Tech stack: Python, Pandas, Pathlib

For building this small project I used -
🔹 File handling in Python
🔹 Time duration calculations with Pandas
🔹 Writing clean & reusable functions
