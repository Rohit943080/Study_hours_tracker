# 📚 Study Hours Tracker ⏳

A simple **Python project** to track and calculate your **daily study hours**.  
This project appends study sessions (date & time studied) into a text file and calculates the **total study time** using **Pandas**.

## 🚀 Features
- ✍️ Append new study records (date & time studied)  
- 📂 Store data in a simple `.txt` file  
- ⏳ Convert times into durations using Pandas  
- 📊 Calculate and display **total study hours**

---

## 🛠️ Technologies Used
- **Python 3**  
- **Pandas**  
- **Pathlib** (for file handling)
